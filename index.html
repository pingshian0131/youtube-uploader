Youtube Uploader Desktop

YouTube 頻道「N流星餡餅N」自用的影片上傳工具

Youtube Uploader Desktop 是一支在頻道擁有者自己的電腦上執行的命令列工具，透過 YouTube Data API 把自製影片上傳到「N流星餡餅N」頻道，並設定標題、說明、標籤、隱私狀態、字幕與縮圖。

這不是公開服務：沒有網站後台、不開放其他人註冊，也不會收集任何使用者的資料。

功能

  • 上傳影片到自己的 YouTube 頻道（含 Shorts）
  • 設定標題、說明、標籤、分類、語言、隱私狀態與排程發布
  • 上傳字幕檔、設定縮圖、加入播放清單
  • 將影片從私人改為公開或不公開

使用的 Google 權限

  • youtube.upload：上傳影片到授權的頻道
  • youtube.force-ssl：管理該頻道影片的字幕、縮圖與隱私狀態

詳細的資料處理方式請見隱私權政策，使用規範請見服務條款。

English

Youtube Uploader Desktop is a personal command-line tool that runs on the channel owner's own computer. It uses the YouTube Data API to upload videos to the YouTube channel “N流星餡餅N” and to set their title, description, tags, privacy status, captions and thumbnail. It is not a public service: there is no server, no sign-up for other users, and no collection of user data.
