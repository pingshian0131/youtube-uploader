隱私權政策

生效日期：2026 年 11 月 17 日

本政策說明 Youtube Uploader Desktop（以下稱「本工具」）如何存取、使用、儲存與分享透過 Google 帳號授權取得的資料。本工具僅供 YouTube 頻道「N流星餡餅N」的擁有者在自己的電腦上使用。

1. 存取的資料

經使用者透過 Google OAuth 同意後，本工具會使用下列權限：

  • https://www.googleapis.com/auth/youtube.upload：上傳影片。
  • https://www.googleapis.com/auth/youtube.force-ssl：讀取頻道名稱與 ID，管理已上傳影片的字幕、縮圖與隱私狀態。

本工具不會讀取 Gmail、聯絡人、雲端硬碟或任何其他 Google 服務的資料。

2. 資料的使用方式

取得的資料只用於執行使用者自己下達的指令：上傳指定的影片、設定其標題與說明等中繼資料、上傳字幕與縮圖、變更隱私狀態，以及顯示目前授權的頻道名稱。本工具不會將資料用於廣告、分析、建立使用者輪廓或訓練任何人工智慧模型。

3. 資料的儲存

  • OAuth 存取權杖只儲存在使用者自己電腦的本機檔案中（權限設為僅擁有者可讀），不會上傳到任何伺服器。
  • 本工具沒有伺服器或資料庫，不在任何雲端保存使用者資料。
  • 本機上傳紀錄只包含影片 ID、標題、檔案路徑與上傳時間，保存在使用者自己的電腦。

4. 資料的分享

本工具不會出售、出租或與第三方分享透過 Google API 取得的資料。唯一的例外是使用者自行設定的上傳通知：上傳完成或隱私狀態變更時，本工具可透過使用者電腦上的 Apple「訊息」App，將影片標題、狀態與連結傳送給使用者自己指定的收件人。

5. Google API 服務使用者資料政策

本工具對於從 Google API 取得之資料的使用與傳輸，將遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）規定。

6. YouTube API 服務

本工具使用 YouTube API 服務。使用本工具即表示您同意 YouTube 服務條款，Google 對資料的處理則適用 Google 隱私權政策。

7. 撤銷授權與刪除資料

  • 您可以隨時在 Google 帳戶的「第三方應用程式與服務」或 Google 安全性設定頁撤銷本工具的存取權。
  • 刪除本機的權杖檔案即可清除本工具保存的授權；本工具沒有在其他地方保存任何資料。

8. 政策變更與聯絡方式

本政策如有變更，會更新於本頁並修改生效日期。有任何問題，請透過 GitHub Issues 聯絡。

Privacy Policy (English)

Effective date: November 17, 2026

Data accessed. With the user's consent via Google OAuth, Youtube Uploader Desktop (“the App”) uses the scopes youtube.upload (upload videos) and youtube.force-ssl (read the channel name and ID; manage captions, thumbnails and privacy status of uploaded videos). It does not access any other Google data.

Use. Data is used only to carry out commands the user runs: uploading the chosen videos, setting their metadata, uploading captions and thumbnails, changing privacy status and showing the authorized channel. It is never used for advertising, analytics, profiling or AI model training.

Storage. OAuth tokens are stored only in a local file on the user's own computer, readable only by its owner. The App has no server or database and stores no user data in the cloud.

Sharing. The App does not sell, rent or share data obtained through Google APIs with third parties. The only exception is an optional notification configured by the user, which sends a video's title, status and link through Apple Messages on the user's computer to recipients the user chooses.

Limited Use. The App's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services. The App uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.

Revocation and deletion. Revoke access at any time at Google security settings. Deleting the local token file removes all data the App keeps.
